# 代码分析器

本技能提供代码分析功能，用于扫描项目结构和搜索字段使用情况，生成包含依赖图的分析报告。

## 功能特点

### 1. 项目结构分析
- 扫描项目目录结构
- 识别代码文件和模块
- 收集导入语句
- 生成文件依赖关系图

### 2. 字段/函数搜索
- 全局搜索指定字段的使用情况
- 收集使用该字段的代码位置
- 提供使用场景的上下文

### 3. 使用模式分类
- 基于规则对使用场景进行分类
- 收集可能的赋值、条件判断等场景

### 4. 报告生成
- 生成结构化的分析报告
- 包含代码引用和行号
- 生成依赖关系图

### 5. 错误处理
- 全面的异常捕获和处理机制
- 详细的错误信息和堆栈跟踪
- 优雅的错误恢复策略

## 工作流程

1. **项目结构扫描**：
   - 扫描项目目录，识别代码文件
   - 收集导入语句
   - 生成文件依赖关系图

2. **字段搜索**：
   - 全局搜索指定字段
   - 收集所有使用该字段的代码位置
   - 记录使用场景的上下文

3. **使用模式分类**：
   - 基于规则对使用场景进行分类

4. **报告生成**：
   - 整合分析结果
   - 生成分析报告
   - 生成依赖关系图

## 注意事项

- 分析结果基于找到的代码，不是绝对结论
- 使用模式分类基于规则，可能不完全准确
- 建议结合实际代码进行验证
- 对于大型项目，分析可能需要较长时间
- 支持的文件类型：Python、JavaScript、TypeScript、Java、C/C++

## 使用指南

### 何时调用
- 当需要分析项目中特定字段的用途和影响时
- 当需要理解复杂代码逻辑时
- 当需要识别潜在的代码问题时
- 当需要优化代码结构时
- 当需要了解代码依赖关系时

### 使用案例

**案例1：分析sourceFrom字段**

**场景**：用户想了解项目中sourceFrom字段的用途和影响。

**操作步骤**：
1. 技能扫描项目目录结构
2. 全局搜索所有使用sourceFrom的代码
3. 分析每个使用场景的上下文
4. 追踪字段的数据流和依赖关系
5. 生成详细的分析报告，包括代码引用和使用逻辑

**案例2：分析函数调用关系**

**场景**：用户想了解某个关键函数的调用关系和影响范围。

**操作步骤**：
1. 技能扫描项目目录结构
2. 搜索该函数的定义和所有调用点
3. 分析函数的参数和返回值使用情况
4. 建立函数调用关系图
5. 生成详细的分析报告

**案例3：代码优化分析**

**场景**：用户想优化项目代码结构。

**操作步骤**：
1. 技能扫描项目目录结构
2. 分析代码依赖关系
3. 识别潜在的代码问题和优化机会
4. 生成优化建议报告

### 操作命令

**手动触发命令**：
- `/analyze <字段名/函数名>` - 分析指定字段或函数
- `/structure` - 分析项目结构
- `/report` - 生成详细分析报告
- `/dependencies` - 分析代码依赖关系

**自动触发**：
- 当用户询问特定字段或函数的用途时自动触发
- 当用户需要了解代码逻辑时自动触发

## 实现细节

代码分析器使用以下技术：

1. **静态代码分析**：
   - 扫描代码文件，提取语法树
   - 分析变量和函数的定义与使用
   - 识别代码模式和潜在问题

2. **依赖关系分析**：
   - 分析文件之间的导入关系
   - 建立模块依赖图
   - 识别循环依赖和冗余依赖

3. **数据流分析**：
   - 追踪变量在不同文件中的传递路径
   - 分析变量的赋值和使用情况
   - 识别变量的影响范围

4. **报告生成**：
   - 整合分析结果
   - 生成结构化的分析报告
   - 提供可视化的依赖关系图

5. **错误处理**：
   - 全面的异常捕获和处理
   - 详细的错误信息和堆栈跟踪
   - 优雅的错误恢复策略

## 最佳实践

- 分析大型项目时，先指定特定的字段或函数，避免分析范围过大
- 结合代码注释和文档，提高分析的准确性
- 定期进行代码分析，及时发现潜在问题
- 利用分析报告指导代码优化和重构
- 对于复杂项目，可以分模块进行分析
- 分析前确保项目代码是可编译的，避免语法错误影响分析结果

## 环境要求

- **Python 3.6 或更高版本**：本技能使用 Python 脚本实现核心功能
- **标准库**：所有脚本只使用 Python 标准库，无需安装额外依赖
- **操作系统**：支持 Windows、Linux 和 macOS

## 使用说明

### 脚本运行方式

1. **通过主入口脚本运行**：
   ```bash
   # 分析项目结构
   python scripts/main.py structure
   
   # 分析指定字段
   python scripts/main.py analyze <字段名>
   
   # 分析代码依赖
   python scripts/main.py dependencies
   
   # 生成报告
   python scripts/main.py report
   ```

2. **直接运行单个脚本**：
   ```bash
   # 分析结构
   python scripts/structure_analyzer.py
   
   # 搜索代码
   python scripts/code_searcher.py <搜索词>
   
   # 分析代码逻辑
   python scripts/logic_analyzer.py <字段名/函数名>
   
   # 生成报告
   python scripts/report_generator.py
   ```

### 环境检测

- 主入口脚本会自动检测 Python 环境
- 如果未检测到 Python 环境，会给出明确的错误提示
- 所有脚本只使用 Python 标准库，无需安装额外依赖

### 跨平台兼容性

- 脚本在 Windows、Linux 和 macOS 上均可运行
- 使用相对路径和标准库，确保跨平台兼容性
- 支持不同操作系统的文件路径格式

### 性能优化建议

- 对于大型项目，可以通过以下方式提高分析速度：
  - 只分析特定目录
  - 只分析特定类型的文件
  - 使用 `--depth` 参数限制目录遍历深度

- 对于频繁分析的项目，可以考虑：
  - 保存分析结果到缓存
  - 增量分析只变化的文件

## 故障排除

### 常见问题及解决方法

1. **分析速度慢**
   - 原因：项目过大或文件过多
   - 解决：限制分析范围，只分析关键目录

2. **分析结果不准确**
   - 原因：代码存在语法错误或复杂的动态代码
   - 解决：确保代码可编译，使用更具体的搜索条件

3. **报告生成失败**
   - 原因：权限不足或磁盘空间不足
   - 解决：检查文件权限，确保磁盘有足够空间

4. **依赖图显示异常**
   - 原因：依赖关系复杂或循环依赖
   - 解决：简化分析范围，使用更具体的依赖分析
