# 代码分析器

本技能提供高级代码分析功能，用于深入理解项目代码结构和逻辑，特别适用于分析特定字段、函数和组件的使用情况。

## 功能特点

### 1. 项目结构分析
- 自动扫描项目目录结构
- 识别主要代码文件和模块
- 建立代码依赖关系图
- 分析项目的整体架构

### 2. 字段/函数分析
- 全局搜索指定字段或函数的使用情况
- 分析字段的定义、赋值和使用场景
- 识别字段的依赖关系和影响范围
- 追踪字段在不同文件中的传递路径

### 3. 代码逻辑分析
- 分析条件判断和逻辑分支
- 识别字段对其他功能的影响
- 分析代码执行流程
- 检测潜在的代码问题

### 4. 详细报告生成
- 生成结构化的分析报告
- 包含代码引用和行号
- 提供可视化的依赖关系图
- 给出优化建议

## 工作流程

1. **项目结构扫描**：
   - 扫描项目目录，识别主要代码文件
   - 分析文件之间的依赖关系
   - 建立项目结构树

2. **字段/函数搜索**：
   - 全局搜索指定字段或函数
   - 收集所有使用该字段的代码位置
   - 分析每个使用场景的上下文

3. **逻辑分析**：
   - 追踪字段的数据流
   - 分析字段的赋值和使用逻辑
   - 识别字段对其他功能的影响

4. **报告生成**：
   - 整合分析结果
   - 生成详细的分析报告
   - 提供优化建议

## 评估分析

**四个功能是否可以聚合到一个技能中：**

是的，这四个功能可以聚合到一个技能中，因为它们相互关联，形成了一个完整的代码分析流程：

1. **项目结构分析** - 为后续的字段/函数分析提供基础
2. **字段/函数分析** - 解决特定字段的使用情况分析问题
3. **代码逻辑分析** - 深入理解字段的工作机制和影响
4. **详细报告生成** - 提供结构化的分析结果和建议

这四个功能相互补充，共同提高代码分析的全面性和准确性，形成了一个完整的代码分析生态系统。

## 使用指南

### 何时调用
- 当需要分析项目中特定字段的用途和影响时
- 当需要理解复杂代码逻辑时
- 当需要识别潜在的代码问题时
- 当需要优化代码结构时

### 使用案例

**案例1：分析sourceFrom字段**

**场景**：用户想了解项目中sourceFrom字段的用途和影响。

**操作步骤**：
1. 技能扫描项目目录结构
2. 全局搜索所有使用sourceFrom的代码
3. 分析每个使用场景的上下文
4. 追踪字段的数据流和依赖关系
5. 生成详细的分析报告，包括代码引用和使用逻辑

**案例2：分析函数调用关系**

**场景**：用户想了解某个关键函数的调用关系和影响范围。

**操作步骤**：
1. 技能扫描项目目录结构
2. 搜索该函数的定义和所有调用点
3. 分析函数的参数和返回值使用情况
4. 建立函数调用关系图
5. 生成详细的分析报告

**案例3：代码优化分析**

**场景**：用户想优化项目代码结构。

**操作步骤**：
1. 技能扫描项目目录结构
2. 分析代码依赖关系
3. 识别潜在的代码问题和优化机会
4. 生成优化建议报告

### 操作命令

**手动触发命令**：
- `/analyze <字段名/函数名>` - 分析指定字段或函数
- `/structure` - 分析项目结构
- `/report` - 生成详细分析报告
- `/dependencies` - 分析代码依赖关系

**自动触发**：
- 当用户询问特定字段或函数的用途时自动触发
- 当用户需要了解代码逻辑时自动触发

## 实现细节

代码分析器使用以下技术：

1. **静态代码分析**：
   - 扫描代码文件，提取语法树
   - 分析变量和函数的定义与使用
   - 识别代码模式和潜在问题

2. **依赖关系分析**：
   - 分析文件之间的导入关系
   - 建立模块依赖图
   - 识别循环依赖和冗余依赖

3. **数据流分析**：
   - 追踪变量在不同文件中的传递路径
   - 分析变量的赋值和使用情况
   - 识别变量的影响范围

4. **报告生成**：
   - 整合分析结果
   - 生成结构化的分析报告
   - 提供可视化的依赖关系图

## 环境要求

- **Python 3.6 或更高版本**：本技能使用 Python 脚本实现核心功能
- **标准库**：所有脚本只使用 Python 标准库，无需安装额外依赖

## 使用说明

### 脚本运行方式

1. **通过主入口脚本运行**：
   ```bash
   # 分析项目结构
   python scripts/main.py structure
   
   # 分析指定字段
   python scripts/main.py analyze <字段名>
   
   # 分析代码依赖
   python scripts/main.py dependencies
   
   # 生成报告
   python scripts/main.py report
   ```

2. **直接运行单个脚本**：
   ```bash
   # 分析项目结构
   python scripts/structure_analyzer.py
   
   # 搜索代码
   python scripts/code_searcher.py <搜索词>
   
   # 分析代码逻辑
   python scripts/logic_analyzer.py <字段名/函数名>
   
   # 生成报告
   python scripts/report_generator.py
   ```

### 环境检测

- 主入口脚本会自动检测 Python 环境
- 如果未检测到 Python 环境，会给出明确的错误提示
- 所有脚本只使用 Python 标准库，无需安装额外依赖

### 跨平台兼容性

- 脚本在 Windows、Linux 和 macOS 上均可运行
- 使用相对路径和标准库，确保跨平台兼容性
