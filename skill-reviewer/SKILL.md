# 技能评审工具

本技能用于评审其他技能是否足够满足用户需求，通过分析技能的结构、功能和实现，提供客观的评估和改进建议。

## 功能特点

### 1. 技能结构分析
- 分析技能的目录结构和文件组织
- 检查技能定义文件的完整性和规范性
- 评估技能的模块化程度和可维护性

### 2. 功能需求匹配
- 分析用户需求与技能功能的匹配程度
- 识别技能的核心功能和缺失功能
- 评估技能的功能覆盖范围

### 3. 代码质量评估
- 分析代码的可读性和可维护性
- 检查代码的错误处理和异常处理机制
- 评估代码的性能和效率

### 4. 文档质量评估
- 检查技能文档的完整性和准确性
- 评估文档的清晰度和易用性
- 分析文档的结构和组织

### 5. 报告生成
- 生成详细的技能评审报告
- 提供客观的评估结果和改进建议
- 支持多种格式的报告输出

## 工作流程

1. **技能扫描**：
   - 扫描技能的目录结构
   - 分析技能定义文件
   - 检查代码文件和文档

2. **需求分析**：
   - 分析用户需求
   - 识别技能的功能点
   - 评估功能与需求的匹配程度

3. **质量评估**：
   - 评估代码质量
   - 评估文档质量
   - 识别潜在的问题和改进空间

4. **报告生成**：
   - 整合评估结果
   - 生成详细的评审报告
   - 提供改进建议

## 评估标准

### 1. 结构完整性
- 技能目录结构是否合理
- 技能定义文件是否完整
- 代码文件是否组织有序

### 2. 功能完整性
- 是否覆盖用户需求的所有方面
- 功能实现是否完整
- 是否有冗余或缺失的功能

### 3. 代码质量
- 代码可读性和可维护性
- 错误处理和异常处理
- 性能和效率

### 4. 文档质量
- 文档的完整性和准确性
- 文档的清晰度和易用性
- 文档的结构和组织

### 5. 用户体验
- 技能的使用是否简单直观
- 错误提示是否清晰
- 响应速度是否合理

## 使用指南

### 何时调用
- 当需要评估技能是否满足用户需求时
- 当需要改进技能的质量时
- 当需要了解技能的优势和劣势时

### 使用案例

**案例1：评估新技能**

**场景**：用户开发了一个新技能，需要评估其是否满足需求。

**操作步骤**：
1. 技能扫描新技能的目录结构
2. 分析技能的功能和实现
3. 评估技能的质量和用户体验
4. 生成详细的评审报告

**案例2：改进现有技能**

**场景**：用户需要改进现有技能的质量。

**操作步骤**：
1. 技能扫描现有技能的目录结构
2. 分析技能的功能和实现
3. 识别潜在的问题和改进空间
4. 生成改进建议报告

### 操作命令

**手动触发命令**：
- `/review <技能路径>` - 评审指定技能
- `/report` - 生成评审报告
- `/help` - 显示帮助信息

**自动触发**：
- 当用户询问技能质量时自动触发
- 当用户需要技能改进建议时自动触发

## 存储结构

```
.trae/skills/skill-reviewer/
├── SKILL.md                  # 技能定义文件
├── scripts/                  # 脚本文件目录
│   ├── main.py               # 主入口脚本
│   ├── structure_analyzer.py # 技能结构分析脚本
│   ├── requirement_matcher.py # 需求匹配脚本
│   ├── quality_evaluator.py  # 质量评估脚本
│   └── report_generator.py   # 报告生成脚本
└── reports/                  # 评审报告目录
    ├── skill_review.md       # 技能评审报告
    └── improvement_suggestions.md # 改进建议报告
```

## 环境要求

- **Python 3.6 或更高版本**：本技能使用 Python 脚本实现核心功能
- **标准库**：所有脚本只使用 Python 标准库，无需安装额外依赖

## 使用说明

### 脚本运行方式

1. **通过主入口脚本运行**：
   ```bash
   # 评审指定技能
   python scripts/main.py review <技能路径>
   
   # 生成评审报告
   python scripts/main.py report
   ```

2. **直接运行单个脚本**：
   ```bash
   # 分析技能结构
   python scripts/structure_analyzer.py <技能路径>
   
   # 匹配需求
   python scripts/requirement_matcher.py <技能路径> <需求描述>
   
   # 评估质量
   python scripts/quality_evaluator.py <技能路径>
   
   # 生成报告
   python scripts/report_generator.py
   ```

### 环境检测

- 主入口脚本会自动检测 Python 环境
- 如果未检测到 Python 环境，会给出明确的错误提示
- 所有脚本只使用 Python 标准库，无需安装额外依赖

### 跨平台兼容性

- 脚本在 Windows、Linux 和 macOS 上均可运行
- 使用相对路径和标准库，确保跨平台兼容性
